<summary>⚡ <b>How to enable the automated Contribution Snake GitHub Action</b></summary>
<br>

To make the contribution snake animate automatically every day:
1. Ensure the file `.github/workflows/snake.yml` exists in this repository.
2. Go to repository **Settings** -> **Actions** -> **General** -> **Workflow permissions**, and select **Read and write permissions**.
3. Go to the **Actions** tab, click on **Generate Snake Contribution Animation**, and trigger **Run workflow**.
4. Once completed, a branch named `output` will be created with the animated SVG!
</details>
